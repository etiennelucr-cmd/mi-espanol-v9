# Mi Español V16.2 — diagnostic de performance

Version basée sur le ZIP GitHub fourni le 19 octobre 2026.

Panneau « ⏱️ Diagnostic V16.2 (facultatif) » dans le menu latéral : temps serveur, appels SQL, attente PostgreSQL, barre latérale et page sélectionnée.

Aucun SQL, mot de passe ni réponse d'exercice n'est affiché. Les temps n'incluent pas la latence réseau du navigateur ni l'intégralité du réveil du serveur.

Cette version sert à mesurer la cause des lenteurs, sans garantie d'accélération immédiate. Aucun changement de schéma Supabase ni des données sauvegardées.

Installation : décompresser le ZIP et transférer son contenu à la racine du dépôt GitHub main. Ne pas ajouter de secrets.

Après déploiement, cliquer sur Phrase suivante, ouvrir Diagnostic dans le menu et envoyer une capture des durées.
