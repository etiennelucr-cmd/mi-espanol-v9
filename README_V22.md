# Mi Español V22 — version cumulée

Base : V21 cumulée. Tous les modules préexistants sont conservés.

## Nouveauté
Dans « Mon aventure V22 » > « Ma journée », ouvrir « Sauvegarder / restaurer mon aventure » pour exporter les étapes de l'arbre, les réponses des mini-défis, les XP et les pièces en JSON, puis les réimporter plus tard.

Cette sauvegarde est **manuelle** : elle ne synchronise pas automatiquement les sessions Streamlit ou les appareils. Elle n'inclut ni les secrets, ni les données du moteur historique PostgreSQL. Conserver le fichier exporté en lieu sûr.

## Limites
Les étapes de l'arbre V18 sont des étapes explorées et ne certifient pas un niveau CECRL. Les évaluations orales/écrites et les contrôles historiques ne sont pas encore agrégés. L'exécution réelle avec Streamlit Cloud et PostgreSQL doit être testée.
