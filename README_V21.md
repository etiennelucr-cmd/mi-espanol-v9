# Mi Español V21 — Version cumulée

Basée sur l'archive V20 cumulée. Tous les modules historiques sont conservés.

## Nouveauté V21

- Accueil « Mon aventure V21 » avec onglet « Ma journée ».
- Programme quotidien adaptable de 15 à 120 minutes (par défaut 2 heures).
- Suggestion de thème CECRL à poursuivre, fondée sur les étapes du module aventure.
- Bilans de mini-défis pour aujourd'hui, les 7 et les 30 derniers jours.
- Suggestion de révision à partir des erreurs de mini-défis.

## Limites

Les bilans V21 et les récompenses aventure sont encore stockés dans la session Streamlit, non durablement. Le niveau CECRL réel ne peut pas être déduit des seuls QCM. L'exécution avec la base cloud doit être testée avant déploiement de production.

## Démarrage

`streamlit run app.py`
