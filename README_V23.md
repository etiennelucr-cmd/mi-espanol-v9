# Mi Español V23 — Espagne et progression CECRL

- Identité visuelle rouge, or, crème dans l’accueil et les cartes de missions.
- Arbre CECRL : seuls le niveau suivi et les niveaux inférieurs sont sélectionnables.
- Les niveaux supérieurs apparaissent verrouillés.
- Attention : le niveau suivi reste modifiable dans la barre latérale. Il ne s’agit pas d’un verrouillage de certification côté serveur. Pour un verrouillage strict, il faudra un champ de niveau validé distinct et contrôlé par les examens enregistrés.
- Les XP ne sont pas utilisés pour débloquer les niveaux.

Conserver les secrets Streamlit et la configuration PostgreSQL lors du déploiement.
