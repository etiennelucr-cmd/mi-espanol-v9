# Mi Español V18 — Arbre de compétences et bilans

- Arbre de compétences thématique A1–C2, 5 étapes par thème.
- Mini-défis de vocabulaire, sélection évitant les mots récents.
- 34 nouvelles entrées ciblées (maison, famille, alimentation) sans doublons exacts.
- Référence aux temps de conjugaison existants par niveau.
- Bilans jour/semaine/mois des mini-défis de la session.
- Navigation en 5 rubriques, pages historiques préservées.

## Limites
Les étapes et les récompenses du nouveau module restent en session Streamlit et ne sont pas persistantes. Les bilans ne couvrent pas encore les évaluations historiques et ne constituent pas un diagnostic CECRL officiel. Les étapes sont des jalons ludiques, pas une validation automatique de maîtrise.

Lancer : `pip install -r requirements.txt` puis `streamlit run app.py`. Configurer `APP_PASSWORD` dans les secrets Streamlit et la base selon le projet existant.
