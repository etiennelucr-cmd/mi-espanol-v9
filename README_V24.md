# Mi Español V24 — España globale

Version cumulée basée sur V23. Ajoute une feuille de style globale commune aux pages de l’application, un thème Streamlit rouge/jaune/crème, et harmonise les composants de navigation, formulaires, cartes, onglets, missions et arbre CECRL.

**Important :** le verrouillage CECRL hérité de V23 utilise toujours le niveau suivi, et non un niveau certifié indépendant. La persistance et la logique métier ne sont pas modifiées.

Déploiement : conserver les secrets Streamlit et la configuration de base de données. Tester les pages sur Streamlit Cloud.
