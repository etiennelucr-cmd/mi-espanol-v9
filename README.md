# Mi Español — V54 compacte

Application Streamlit multilingue avec villes interactives, situations évolutives et puzzles de phrases.

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Nouveautés V54

- Onglet **Puzzle de phrases** dans chaque lieu : reconstruire des phrases dans les quatre langues, mot après mot.
- Correction et enregistrement des résultats par langue, ville et lieu.
- Archive nettoyée : anciens journaux README et doublons de scripts de test retirés, modules et ressources conservés.

Les niveaux CECRL ne sont pas certifiés par les puzzles. Les villes restent des simulations.
