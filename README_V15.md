# Mi Español V15 — dossier complet

## Nouveau
Dans les contrôles et les révisions, ajout de six phrases bilingues complètes pour chacun des 17 temps du parcours de conjugaison, dont le passé composé (« Yo he comido con mi familia. »). Le temps est choisi par le planning hebdomadaire. Les exercices conservent l'alternance français→espagnol et espagnol→français, et les exemples des leçons.

## Limites
Ces six phrases par temps sont communes aux thèmes utilisant ce temps : elles ne sont pas toutes liées au vocabulaire du thème. Une même paire peut revenir dans l'autre direction pour atteindre 20 questions. Le correcteur reste strict. Le temps du planning est lu lors de la création du lot ; si le planning change pendant une session déjà ouverte, terminer le lot ou rafraîchir la session pour en obtenir un nouveau.

## Vérifications
Compilation Python et génération de 20 exercices pour toutes les leçons A1-C2 réussies. Pas de test en direct avec Supabase/Streamlit.

## Installation
Décompresser et envoyer le contenu à la racine du dépôt GitHub mi-espanol-v9 sur main. Ne pas écraser le dossier .streamlit ni ajouter de secrets.
