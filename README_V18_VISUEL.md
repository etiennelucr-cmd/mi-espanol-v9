# Mi Español V18 — Interface aventure

Nouveautés : cartes de missions colorées, avatars de personnages sous forme d’illustrations emoji, dialogues en cartes, arbre CECRL avec nœuds visuels et connecteurs.

Les activités, la progression CECRL historique et les modules existants sont conservés. Les avatars sont des emoji (pas encore des illustrations graphiques personnalisées). Les récompenses restent en session Streamlit.

Lancer : `streamlit run app.py`.
