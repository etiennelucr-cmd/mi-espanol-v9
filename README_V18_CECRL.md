# Mi Español V18 — Aventure CECRL

Nouveau menu « 🌍 Aventure CECRL A1–C2 ».

- Exploration libre des six niveaux CECRL.
- Liste des leçons historiques de chaque niveau, avec leurs objectifs.
- Missions de vocabulaire par thème, alimentées directement par le lexique existant.
- Questions variées tirées aléatoirement, évitant les mots récents tant que possible.
- Récompenses XP et pièces, sans pénalités ni modification des validations pédagogiques.
- Présentation progressive des temps de conjugaison existants et renvoi au module complet.

**Limites :** les récompenses de cette nouvelle page sont en session seulement ; la maîtrise CECRL n'est pas certifiée par les mini-jeux. Les temps et les leçons sont ceux déjà présents dans le projet : aucune couverture exhaustive A1-C2 n'est garantie sans audit pédagogique détaillé. L'application n'a pas été testée avec la base PostgreSQL en production.
