# Mi Español V63 — rencontres et immersion sociale

Lancer avec `streamlit run app.py`.

Nouveautés : cinquième carte « Mes rencontres », 4 langues, amis par ville, animaux, messages libres à reconnaissance simple, réponses guidées, liens d’amitié, soirées, disputes, familles, invitations et changement de ville. Navigation par widgets Streamlit sans liens HTML rechargeant la page.

**Limites honnêtes :** simulation légère scénarisée ; pas de véritable intelligence autonome, pas de génération conversationnelle libre, pas encore de sauvegarde permanente après redémarrage. Les animaux et familles sont représentés dans les histoires, pas encore des agents complets. Les dialogues sociaux ne modifient pas les estimations CECRL, pour éviter une progression artificielle.
